네온 시티 그림 넣는 방법

1. 그림 파일을 아래 이름 그대로 저장합니다.

   배경 (폴더: public/story/bg/)  규격 960 x 300 권장, PNG 또는 JPG
     rain.png     비 내리는 도시 (시작 장면)
     tower.png    오르빗 타워
     alarm.png    경보
     alley.png    뒷골목
     vault.png    지하 금고·데이터 센터
     port.png     항만
     seraph.png   세라프 연구소
     neon.png     네온 거리 (엔딩)

   초상화 (폴더: public/story/portraits/)  세로로 긴 그림, 예: 400 x 600, PNG 권장
     riko.png  (리코)
     mira.png  (미라)
     kai.png   (카이)
     ada.png   (에이다)
     vex.png   (벡스)

2. 파일을 넣고 저장한 뒤 브라우저를 새로고침(Ctrl+F5)하면 바뀝니다.
3. 파일 이름을 바꾸고 싶으면 src/story/storyImages.js 의 경로도 같이 고칩니다.
4. 파일이 없으면 지금의 코드 그림이 그대로 나옵니다. 일부만 넣어도 됩니다.

참고: 다른 게임이나 작품의 그림을 그대로 쓰면 저작권 문제가 생깁니다. 직접 그리거나 라이선스가 허용된 그림을 쓰세요.
