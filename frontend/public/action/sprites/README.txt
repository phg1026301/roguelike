검의 길 스프라이트 시트 (선택 사항)

이 폴더에 아래 이름의 PNG 파일을 넣으면 게임이 도형 그림 대신 그림 파일을 씁니다.
파일이 없으면 기존 도형 그림을 그대로 씁니다. 한 개만 넣어도 그 캐릭터만 바뀝니다.

파일 이름
  knight.png   검사
  mage.png     마법사
  slime.png    슬라임
  goblin.png   고블린
  boss.png     오크 대장 그롬

시트 규격
  - 가로 4칸(프레임)에 세로 여러 행. 한 칸은 정사각형 (예: 256×256 이면 한 칸 64×64, 행 4개 = 1024px 높이까지 가능)
  - 행(위에서 아래로)
      0행: 기본 자세 (서 있기, 숨쉬기). 적은 이동
      1행: 걷기. 적은 공격 예고 자세
      2행: 공격. 적은 맞았을 때
      3행: 회피·피격. 보스는 휴식 자세
  - 칸(왼쪽에서 오른쪽)은 애니메이션 프레임. 초당 8칸씩 넘어간다
  - 캐릭터는 바라보는 방향이 오른쪽. 왼쪽을 볼 때는 게임이 자동으로 뒤집는다
  - 발끝(또는 몸 아래쪽 중앙)이 칸 아래쪽 가운데에 오도록 그린다
  - 배경은 투명(PNG 알파)이어야 바닥이 보인다

예: 그림을 만든 뒤 frontend/public/action/sprites/knight.png 로 저장하고 배포하면 된다.
